# Messy Python Code Improvement

## About the Project
This project demonstrates how messy and repetitive Python code can be improved to make it more readable, organized, and reusable.

## Files
- `messy_code.py` — The original student marks calculator with repetitive code.
- `improved_code.py` — The refactored version using functions, dictionaries, built-in functions, and formatted output.

## Features
- Calculates total and average marks.
- Assigns grades based on average marks.
- Displays a report for each student.
- Uses functions to improve code reusability.
- Uses f-strings for clear output.

## Technologies Used
- Python 3

## What I Learned
- Writing reusable functions.
- Organizing data using dictionaries.
- Improving code readability.
- Refactoring repetitive code.
- Using Python's built-in functions.

## How to Run
Run either file using Python:

```bash
python messy_code.py
python improved_code.py
```
